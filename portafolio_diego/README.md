# Portafolio profesional de Diego Betancourt

Sitio estático, responsive y sin dependencias externas.

## Publicación recomendada

1. Crear en GitHub un repositorio público llamado `portafolio-diego-betancourt`.
2. Subir `index.html`, `styles.css` y la carpeta `assets`.
3. Activar GitHub Pages en **Settings → Pages → Deploy from a branch → main / root**.
4. Revisar el sitio desde celular y computador.
5. Añadir luego capturas de proyectos sin datos personales, credenciales, IP, teléfonos de clientes ni información real de usuarios.

## Antes de publicar

- Confirmar estado laboral y disponibilidad.
- Revisar que el teléfono no aparezca públicamente si no se desea.
- Confirmar el alcance exacto de la participación en Amparo's.
- Sustituir cualquier captura por datos ficticios.
- Aprobar las dos hojas de vida incluidas.
